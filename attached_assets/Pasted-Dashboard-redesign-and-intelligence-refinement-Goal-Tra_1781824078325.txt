Dashboard redesign and intelligence refinement.

Goal:

Transform the Dashboard from a reporting page into a decision-making page that answers:

"What do I need to know before making my next coffee?"

Use modern premium SaaS design principles (Linear, Raycast, Notion, Apple). Less reporting, more intelligence.

- Best Rated list

--------------------------------------------------
BEST PERFORMING WINDOWS
--------------------------------------------------

Keep this section.

However:

Do NOT calculate windows using simple min/max values.

Use robust statistics.

Requirements:

- Use reference shots first
- Use highly rated shots second
- Weight preference ratings where available
- Remove obvious outliers
- Prefer median and clustering analysis
- Do not allow a single extreme value to define a window

Example:

If first pour delays are:

5, 6, 6, 7, 7, 8, 12

Display:

6–8s

NOT:

5–12s

Goal:

Display the user's true sweet spot.
