# BigShotEspresso AI Onboarding Strategy

## Purpose
The application stores the data.
The AI helps users understand the data.

## Workflow
1. Create BigShotEspresso account.
2. Add equipment.
3. Log beans, bags, and shots.
4. Create ChatGPT, Claude, Gemini, or local AI project.
5. Upload BigShotEspresso Knowledge Base.
6. Paste project instructions.
7. Upload optional exports.

## Philosophy
BigShotEspresso provides context.
AI provides guidance.

## Goal
Help users answer:
- What was my best shot?
- Why did it work?
- How do I reproduce it?
- Where should I start with a new bag?
