# BigShotEspresso Dashboard Intelligence

## Purpose
The dashboard should be a coffee control center.

## Current Baseline
Show:
- Active bag
- Dose
- Yield
- Temperature
- Grind setting
- Grind time

## Current Bag Intelligence
Show:
- Bag open days
- Reference shots
- Average rating
- Best yield range
- Best first pour range

## Grind Drift Intelligence
Compare current bag to previous bags.

## Next Shot Watchlist
Provide concise actionable guidance.

## Dashboard Test
Does this help the user make better coffee today?
