# BigShotEspresso Experiment Index

This is the authoritative register of formal `BSE-RD` experiments. An ID does not imply that work is SR&ED-eligible.

## Status vocabulary

- **Proposed:** registered but not started.
- **In progress:** protocol fixed and execution underway.
- **Complete:** results and evidence recorded.
- **Paused:** execution stopped with reason and preserved state.
- **Abandoned:** intentionally stopped; reason and learning retained.
- **Retrospective:** reconstructed later from identified evidence.

## ID allocation rule

- IDs are sequential within the calendar year.
- Never reuse or renumber an allocated ID.
- Cancelled or duplicate entries remain in the register with an explanation.
- Historical work reconstructed later receives the next available ID; it is not inserted into an earlier number to imply contemporaneous creation.

## Minimum registration fields

Before changing an experiment to **In progress**, record:

- technological problem and uncertainty;
- existing knowledge/baseline;
- testable hypothesis;
- protocol and controls;
- dataset definition and provenance;
- outputs/metrics and stop conditions;
- evidence-storage location;
- responsible person and start date.
