# Operational Success Intelligence

## Research question

> How operationally successful is timed dosing when basket dose is not weighed?

## Required concepts

- Initial Grinder Output
- Actual Basket Dose
- Dose Variance
- Timed-dose variance
- Yield Target Window
- No-Weigh Operation Mode
- No-weigh shot simulation
- Historical Success Window

## Boundary

OSI evaluates whether measured DCI consistency is operationally sufficient without weighing. It remains separate from DCI.

## Status

**Conceptual/evidence-ready, not formula-ready.** No success threshold may be invented. Historical windows and simulation rules require approval.
