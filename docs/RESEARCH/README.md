## Research status vocabulary

- **Conceptual:** problem and scope documented.
- **Evidence-ready:** required source fields exist and are verified.
- **Formula-ready:** calculations and thresholds are approved.
- **Implementation-ready:** architecture, contract, tests, and rollout are approved.
- **Implemented:** code exists and verification passes.

No engine is currently certified as implementation-ready.
