# Hopper Mechanics Intelligence

## Research question

How do Hopper state, fullness, transitions, and bean-feed conditions affect grinder output and correction behavior?

## Scope

- Hopper fullness effects on Initial Output
- Fill and top-up frequency
- Dose-correction behavior
- Hopper Range Baseline comparisons
- State continuity and phase transitions
- Interaction with DCI and OSI

## State-system requirement

The Hopper subsystem is not merely a logging table. It must preserve fills, top-ups, assignments, transitions, cleanouts, waste, and reconciliation evidence.

## Status

**Conceptual/evidence-ready, not implementation-ready.** Percentage denominator, event rules, and state-continuity behavior remain unresolved.
