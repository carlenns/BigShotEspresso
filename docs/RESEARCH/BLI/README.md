# Bag Lifecycle Intelligence

## Research question

How does coffee performance evolve from Bag opening through end-of-Bag?

## Scope

- Days since open
- Grind drift and adjustment burden
- Rating, preference, and reference-shot trends
- Lifecycle timing/yield windows
- Bag phase and aging stability
- Buying and Bag-size evidence

## Status

**Conceptual/evidence-ready, not implementation-ready.** Lifecycle thresholds and confidence rules require approval.
